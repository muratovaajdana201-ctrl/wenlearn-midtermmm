Quiz — Week 2: CSS Basics

10 questions: 7 on theory and 3 on code. Choose your answers, then press Check Answers.

1. What does CSS stand for? Theory

Correct answer: Cascading Style Sheets. CSS means Cascading Style Sheets. It makes pages presentable and keeps styling separate from the HTML.

2. Which type of CSS is written in a separate .css file and connected with the <link> tag? Theory

Correct answer: External. External CSS lives in its own .css file and is linked in <head>, so one file can style many pages.

3. Where is internal CSS written? Theory

Correct answer: Inside a <style> tag in the <head>. Internal CSS is placed in a <style> tag in the head section. It is useful when one page needs unique styles.

4. Which selector is used to target one specific, unique element? Theory

Correct answer: ID selector (#header). An ID must be unique on the page, so #header selects only one element. Classes can be shared by many elements.

5. In the box model, what is the space between the content and the border? Theory

Correct answer: Padding. Padding is the space inside the box, around the content. Margin is the space outside the border.

6. Which position value keeps an element in the same place on the screen while the page scrolls? Theory

Correct answer: fixed. position: fixed stays in place on the screen. static is the default normal flow, relative is offset from its normal place.

7. Which of these is a web-safe monospace font? Theory

Correct answer: Courier New. Courier New (and Courier) are monospace. Georgia is serif and Comic Sans MS is cursive.

8. What type of CSS is used in this code? Code 
<p style="color: blue;">Hello</p>

Correct answer: Inline CSS. The style is written right inside the tag with the style attribute, so it is inline CSS.

9. What does this rule select? Code 
nav a {
  color: green;
}

Correct answer: All links that are inside a nav element. A space between selectors makes a descendant selector: every a nested inside nav.

10. How will the text look in the browser? Code 
h2 {
  text-transform: uppercase;
  text-align: center;
}

<h2>Hello world</h2>

Correct answer: HELLO WORLD, centered. text-transform: uppercase changes all letters to capitals and text-align: center centers the line.

Green = correct answer, red = your wrong choice.
