Week 1: HTML Basics

A website has a frontend (everything the user sees) and a backend (the server side: how the site works and stores data). The frontend is built with three languages:

  • HTML – how the page is structured
  • CSS – how it looks
  • JavaScript – how it functions

Internet and WWW

The Internet is a global network of computers. The World Wide Web is the collection of websites on the Internet. It works on the client–server model: the browser (client) sends a request and the server responds with a web page.

HTML elements, tags and attributes

HTML (Hyper Text Markup Language) describes the structure of a page with elements. An element has a start tag, content and an end tag, for example <b>text</b>. Browsers do not show the tags, they use them to render the content. An attribute tells the browser how to do something, for example href or src.

Nested tags must be closed in the right order: the last tag opened is the first tag closed.

<p><b><em>Correct nesting</em></b></p>

The basic skeleton

<html> wraps the whole page, <head> holds the title and styles, <body> holds the content you see.

<!DOCTYPE html>
<html>
<head>
  <title>Astana IT University</title>
</head>
<body>
  This is what is displayed.
</body>
</html>

Text tags

TagMeaning
<h1> … <h6>Headings, from the largest to the smallest
<p>A paragraph, a block of text
<br>A line break without a new paragraph
<b>, <em>Bold and emphasized text

Tables

<table> contains rows <tr>; a row contains data cells <td> or header cells <th>. Use <caption>, <thead>, <tbody> and <tfoot> for structure, and colspan / rowspan to join cells.

Lists

<ul> is an unordered list with bullets, <ol> is an ordered list with numbers. Each item is an <li>.

Links, images, forms

<a href="https://du.astanait.edu.kz/login">DU Astana IT University</a>
<img src="graphics/chef.gif" alt="Chef">
<form>
  <label>Name:</label>
  <input type="text">
  <input type="submit" value="Submit">
</form>

<img> is an empty tag: it has only attributes and no closing tag.

Tools and publishing

Tools: VS Code (editor), GitHub (version control) and browser DevTools (inspecting and debugging). To publish a site: create a GitHub repository, upload the files (the main page must be index.html), enable GitHub Pages in Settings and open your-username.github.io/your-repo-name.

Week 2: CSS Basics

CSS (Cascading Style Sheets) makes web pages presentable and keeps styling separate from the HTML.

Three types of CSS

  • Inline – in the style attribute of a tag.
  • Internal – in a <style> tag inside <head>.
  • External – a separate .css file linked with <link>.
<link rel="stylesheet" href="css/style.css">

CSS syntax and selectors

A rule has a selector and declarations. Each declaration is a property and a value.

p {
  color: red;
}
SelectorExampleTargets
ElementpAll elements of that tag
Class.button-styleElements sharing a class
ID#headerOne unique element
Descendant.nav aElements nested inside others
Universal*Every element

Text formatting and fonts

Common properties: color, text-align, font-size (px, em, rem), direction, text decoration and text-transform. Web-safe fonts work on most systems without a download:

  • Serif: Times New Roman, Georgia, Cambria
  • Sans-serif: Arial, Calibri, Trebuchet MS, Century Gothic
  • Monospace: Courier New, Courier
  • Cursive: Comic Sans MS

Box model

Every element is a box: content (text, images), padding (space inside), border (line around content) and margin (space outside).

Positioning

staticDefault, normal document flow

stickySwitches between relative and fixed on scroll

Week 3: Flexbox and Grid

Flexbox (one-dimensional)

Flexbox arranges items in a row or a column. Items can grow to fill space or shrink to fit. It can center content vertically and make columns equal in height.

  • Flex container – parent with display: flex
  • Flex items – its direct children
  • Main axis – the primary direction of the layout
  • Cross axis – perpendicular to the main axis
LevelPropertyPurpose
Containerflex-directionrow, row-reverse, column, column-reverse
Containerjustify-contentAlign on the main axis (center, space-between...)
Containeralign-itemsAlign on the cross axis
Containerflex-wrapnowrap, wrap, wrap-reverse
Itemflex-grow / flex-shrink / flex-basisHow an item grows, shrinks, and its start size
Itemalign-self / orderOverride alignment for one item, change order
.container {
  display: flex;
  padding: 12px;
}
.item {
  flex: 1;
  margin: 4px;
}

Grid (two-dimensional)

Grid works with rows and columns at the same time. Terms: grid container, grid items, track (row or column), area, line and cell.

FeatureMeaning
frA fraction of the available space
minmax(min, max)Track that resizes between two values
repeat(n, value)Repeats a track definition
grid-template-columns / rowsNumber and size of columns and rows
gapSpace between tracks
grid-column / grid-row / grid-areaWhere an item is placed
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 32px;
}

Flexbox vs Grid

FlexboxGrid
DirectionRow or columnRows and columns
Best forNavbars, menus, buttons, form controlsFull page layout, dashboards, galleries

They work together: use Grid for the large-scale layout and Flexbox to align content inside grid cells.

Week 4: Bootstrap and Media Queries

Bootstrap is an open-source front-end framework from Twitter. You add ready-made classes to HTML elements instead of writing long CSS from scratch.

Adding Bootstrap

The easiest way is a CDN link in <head>. You can also download the files from getbootstrap.com or install with npm install bootstrap.

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

Grid system and containers

Bootstrap uses 12 columns. Structure: container, then row, then columns. .container has a fixed max-width per breakpoint; .container-fluid spans the full viewport width.

<div class="container">
  <div class="row">
    <div class="col-4">Hello</div>
    <div class="col-4">My name</div>
    <div class="col-4">is Kuralay</div>
  </div>
</div>

Responsive breakpoints (mobile-first)

BreakpointPrefixScreen
Extra small.col-< 576px (columns stack)
Small.col-sm≥ 576px
Medium.col-md≥ 768px
Large.col-lg≥ 992px
Extra large.col-xl≥ 1200px

Example: col-12 col-md-3 col-lg-2 is full width on phones, 3 of 12 columns on tablets and 2 of 12 on desktops.

Utilities and components

  • text-center, text-success, text-danger – text alignment and color
  • mt-3 (margin-top 1rem), p-4 (padding 1.5rem) – spacing
  • z-3, position-absolute – stacking and positioning
  • Components: buttons (btn btn-primary), navbar, cards, forms

Media queries

A media query applies styles based on device characteristics: max-width, min-width or orientation.

@media (max-width: 575px) {
  /* mobile styles */
}
