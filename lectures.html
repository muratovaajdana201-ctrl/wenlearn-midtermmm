Week 1: HTML Basics

A website has a frontend (everything the user sees) and a backend (the server side: how the site works and stores data). The frontend is built with three languages:

  • HTML - how the page is structured
  • CSS - how it looks
  • JavaScript - how it functions

Internet and WWW

The Internet is a global network of computers. The World Wide Web is the collection of websites on the Internet. It works on the client-server model: the browser (client) sends a request and the server responds with a web page.

HTML elements, tags and attributes

HTML (Hyper Text Markup Language) describes the structure of a page with elements. An element has a start tag, content and an end tag, for example <b>text</b>. Browsers do not show the tags, they use them to render the content. An attribute tells the browser how to do something, for example href or src.

Nested tags must be closed in the right order: the last tag opened is the first tag closed.

<p><b><em>Correct nesting</em></b></p>

The basic skeleton

<html> wraps the whole page, <head> holds the title and styles, <body> holds the content you see.

<!DOCTYPE html>
<html>
<head>
  <title>Astana IT University</title>
</head>
<body>
  This is what is displayed.
</body>
</html>

Text tags

Tag Meaning
<h1> … <h6> Headings, from the largest to the smallest
<p> A paragraph, a block of text
<br> A line break without a new paragraph
<b>, <em> Bold and emphasized text

Tables

<table> contains rows <tr>; a row contains data cells <td> or header cells <th>. Use <caption>, <thead>, <tbody> and <tfoot> for structure, and colspan / rowspan to join cells.

Lists

<ul> is an unordered list with bullets, <ol> is an ordered list with numbers. Each item is an <li>.

Links, images, forms

<a href="https://du.astanait.edu.kz/login">DU Astana IT University</a>
<img src="graphics/chef.gif" alt="Chef">
<form>
  <label>Name:</label>
  <input type="text">
  <input type="submit" value="Submit">
</form>

<img> is an empty tag: it has only attributes and no closing tag.

Tools and publishing

Tools: VS Code (editor), GitHub (version control) and browser DevTools (inspecting and debugging). To publish a site: create a GitHub repository, upload the files (the main page must be index.html), enable GitHub Pages in Settings and open your-username.github.io/your-repo-name.

Week 2: CSS Basics

CSS (Cascading Style Sheets) makes web pages presentable and keeps styling separate from the HTML.

Three types of CSS

  • Inline - in the style attribute of a tag.
  • Internal - in a <style> tag inside <head>.
  • External - a separate .css file linked with <link>. 
<link rel="stylesheet" href="css/style.css">

CSS syntax and selectors

A rule has a selector and declarations. Each declaration is a property and a value.

p {
  color: red;
}
Selector Example Targets
Element p All elements of that tag
Class .button-style Elements sharing a class
ID #header One unique element
Descendant .nav a Elements nested inside others
Universal * Every element

Text formatting and fonts

Common properties: color, text-align, font-size (px, em, rem), direction, text decoration and text-transform. Web-safe fonts work on most systems without a download:

  • Serif: Times New Roman, Georgia, Cambria
  • Sans-serif: Arial, Calibri, Trebuchet MS, Century Gothic
  • Monospace: Courier New, Courier
  • Cursive: Comic Sans MS

Box model

Every element is a box: content (text, images), padding (space inside), border (line around content) and margin (space outside).

Positioning

Value Behaviour
static Default, normal document flow
relative Offset from its normal position
absolute Relative to the nearest positioned ancestor or the viewport
fixed Stays in place on screen when scrolling
sticky Switches between relative and fixed on scroll

Week 3: Flexbox and Grid

Flexbox (one-dimensional)

Flexbox arranges items in a row or a column. Items can grow to fill space or shrink to fit. It can center content vertically and make columns equal in height.

  • Flex container - parent with display: flex
  • Flex items - its direct children
  • Main axis - the primary direction of the layout
  • Cross axis - perpendicular to the main axis
Level Property Purpose
Container flex-direction row, row-reverse, column, column-reverse
Container justify-content Align on the main axis (center, space-between...)
Container align-items Align on the cross axis
Container flex-wrap nowrap, wrap, wrap-reverse
Item flex-grow / flex-shrink / flex-basis How an item grows, shrinks, and its start size
Item align-self / order Override alignment for one item, change order 
.container {
  display: flex;
  padding: 12px;
}
.item {
  flex: 1;
  margin: 4px;
}

Grid (two-dimensional)

Grid works with rows and columns at the same time. Terms: grid container, grid items, track (row or column), area, line and cell.

Feature Meaning
fr A fraction of the available space
minmax(min, max) Track that resizes between two values
repeat(n, value) Repeats a track definition
grid-template-columns / rows Number and size of columns and rows
gap Space between tracks
grid-column / grid-row / grid-area Where an item is placed 
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 32px;
}

Flexbox vs Grid

Flexbox Grid
Direction Row or column Rows and columns
Best for Navbars, menus, buttons, form controls Full page layout, dashboards, galleries

They work together: use Grid for the large-scale layout and Flexbox to align content inside grid cells.

Week 4: Bootstrap and Media Queries

Bootstrap is an open-source front-end framework from Twitter. You add ready-made classes to HTML elements instead of writing long CSS from scratch.

Adding Bootstrap

The easiest way is a CDN link in <head>. You can also download the files from getbootstrap.com or install with npm install bootstrap.

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

Grid system and containers

Bootstrap uses 12 columns. Structure: container, then row, then columns. .container has a fixed max-width per breakpoint; .container-fluid spans the full viewport width.

<div class="container">
  <div class="row">
    <div class="col-4">Hello</div>
    <div class="col-4">My name</div>
    <div class="col-4">is Kuralay</div>
  </div>
</div>

Responsive breakpoints (mobile-first)

Breakpoint Prefix Screen
Extra small .col- < 576px (columns stack)
Small .col-sm ≥ 576px
Medium .col-md ≥ 768px
Large .col-lg ≥ 992px
Extra large .col-xl ≥ 1200px

Example: col-12 col-md-3 col-lg-2 is full width on phones, 3 of 12 columns on tablets and 2 of 12 on desktops.

Utilities and components

  • text-center, text-success, text-danger - text alignment and color
  • mt-3 (margin-top 1rem), p-4 (padding 1.5rem) - spacing
  • z-3, position-absolute - stacking and positioning
  • Components: buttons (btn btn-primary), navbar, cards, forms

Media queries

A media query applies styles based on device characteristics: max-width, min-width or orientation.

@media (max-width: 575px) {
  /* mobile styles */
}
Device Width Query
Mobile < 576px (max-width: 575px)
Tablet 576px-768px (min-width: 576px) and (max-width: 768px)
Laptop 769px-992px (min-width: 769px) and (max-width: 992px)
Desktop > 992px (min-width: 993px)

Week 5: Bootstrap Grid and Components

In Week 4 we met the 12-column grid. This week we use the grid for real page layouts and add Bootstrap components: ready-made blocks such as the navbar, cards, alerts, forms and modals.

Grid: offsets, ordering, nesting, gutters

Feature Class What it does
Offset offset-md-3 Pushes a column to the right by 3 columns
Auto layout col Equal-width columns that share the free space
Order order-1 / order-md-2 Changes the visual order of columns
Gutters g-3, gx-4, gy-2 Space between columns (all, horizontal, vertical)
Alignment align-items-center, justify-content-between Aligns columns inside a row (Flexbox under the hood)
Nesting row inside col A column can contain its own row with 12 new columns

If the columns in one row add up to more than 12, the extra column wraps to the next line.

<div class="container">
  <div class="row g-3 justify-content-center">
    <div class="col-12 col-md-6 offset-md-3">Centered 6 of 12</div>
  </div>
</div>

Display utilities

Show or hide elements at a breakpoint: d-none d-lg-block hides an element below 992px and shows it from lg up. d-flex turns an element into a Flexbox container. Other helpful utilities: w-100, bg-light, border rounded, shadow, fw-bold.

Navbar

A responsive navbar collapses into a hamburger button on small screens. navbar-expand-lg means: expanded from 992px, collapsed below.

<nav class="navbar navbar-expand-lg bg-light">
  <div class="container">
    <a class="navbar-brand" href="#">WebLearn</a>
    <button class="navbar-toggler" data-bs-toggle="collapse"
            data-bs-target="#menu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item"><a class="nav-link" href="#">Home</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Lectures</a></li>
      </ul>
    </div>
  </div>
</nav>

Cards, buttons, badges, alerts

Component Main classes
Card card, card-img-top, card-body, card-title, card-text
Button btn btn-primary, btn-outline-secondary, btn-lg, btn-sm
Badge badge text-bg-success
Alert alert alert-success / alert-danger / alert-warning
List group list-group, list-group-item 
<div class="card" style="width: 18rem;">
  <div class="card-body">
    <h5 class="card-title">Week 5</h5>
    <p class="card-text">Bootstrap components.</p>
    <a href="#" class="btn btn-primary">Read</a>
  </div>
</div>

Forms

Use form-label, form-control, form-select and form-check. Validation states: is-valid and is-invalid with invalid-feedback for the message.

<div class="mb-3">
  <label for="email" class="form-label">Email</label>
  <input type="email" class="form-control" id="email">
</div>

Modal and JavaScript components

Modal, collapse, carousel and dropdown need Bootstrap's JavaScript. Add the bundle (it includes Popper) before the end of <body>: bootstrap.bundle.min.js. Then connect elements with data attributes: data-bs-toggle (what to do) and data-bs-target (which element).

<button class="btn btn-primary" data-bs-toggle="modal"
        data-bs-target="#info">Open</button>

<div class="modal fade" id="info" tabindex="-1&">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header"><h5 class="modal-title">Hello</h5></div>
      <div class="modal-body">Modal text</div>
    </div>
  </div>
</div>

Week 6: JavaScript Basics

JavaScript is a high-level, dynamic, single-threaded programming language that powers interactivity on the modern web. It was created by Brendan Eich at Netscape Communications and runs directly in the browser, where it can update HTML and CSS dynamically.

HTML vs CSS vs JavaScript

  • HTML is the skeleton of the web: structure and content.
  • CSS is the clothes: how the page looks.
  • JavaScript adds life: behavior and interaction.

Including JavaScript

Internal: code between <script> tags. External: a reusable .js file linked with src.

<script>
  console.log("Hello, AITU!");
</script>

<script src="js/main.js"></script>

Output

Method Description
innerHTML Writes into an HTML element: elem.innerHTML = 5 + 6;
document.write() Writes into the HTML output stream
window.alert() Shows a pop-up alert box
console.log() Writes into the browser developer console

Variables: let, const, var

Keyword Scope Reassign When to use
var Function Yes Old style (before ES6, 2015): avoid
let Block Yes Values that change: counter, score, total
const Block No Default choice: values that do not change

Data types

Type Kind Example
String Primitive "AITU" (single, double quotes or backticks)
Number Primitive 42, 3.14
BigInt Primitive 9007199254740991n
Boolean Primitive true / false
Undefined Primitive let x; (declared, no value)
Null Primitive let y = null; (empty on purpose)
Object Reference { name: "John" }
Array Reference ["apple", 1, true]

The typeof operator returns the type of a value: typeof "AITU" is "string".

Operators

Group Operators
Arithmetic + - * / % ** ++ --
Assignment = += -= *= /=
Comparison == === != !== > < >= <=
Logical && (and) || (or) ! (not)
Ternary condition ? valueIfTrue : valueIfFalse 
console.log(10 % 3);   // 1 (remainder)
console.log(2 ** 3);    // 8
let x = 5; x++;         // 6
let name = "Ai"; name += "da";  // "Aida"

Type coercion and == vs ===

Type coercion is the automatic (implicit) or manual (explicit) conversion of one type to another. == converts types first and then compares; === needs the same type and the same value. Rule: always use === and !==.

console.log("5" + 3);    // "53" (number becomes text)
console.log("5" - 3);    // 2    (text becomes number)
console.log(5 == "5");   // true
console.log(5 === "5");  // false
Number("42");            // explicit conversion

Conditions

Conditions run code only when something is true. Use if, else if, else, the ternary operator or switch.

let score = 85;
if (score >= 90) {
  console.log("A");
} else if (score >= 70) {
  console.log("B");
} else {
  console.log("Try again");
}

let status = score >= 50 ? "pass" : "fail";

Loops

Loops repeat code. for is used when the number of repeats is known, while checks the condition first, do...while runs at least once. break stops a loop, continue skips one step.

for (let i = 1; i <= 3; i++) {
  console.log(i);          // 1, 2, 3
}

let n = 3;
while (n > 0) { n--; }

do {
  n++;
} while (n < 3);

Functions

A function is a reusable block of code that performs a task when it is invoked. It has the function keyword, a name, parentheses with parameters and a body. A function must be defined before use and runs only when invoked. return sends a value back. Arrow functions are a short form.

function add(a, b) {
  return a + b;
}
console.log(add(2, 3));   // 5

const square = (x) => x * x;

Week 7: Arrays, Loops and DOM Manipulation

This week we build a mini-app: data is stored in an array, a loop goes through it and the DOM shows the result on the page.

Arrays

An array stores many values in one variable. Items have an index that starts from 0. The length property returns the number of items.

const topics = ["HTML", "CSS", "JS"];
console.log(topics[0]);       // "HTML"
console.log(topics.length);   // 3
Method What it does
push(x) / pop() Add to the end / remove the last item
unshift(x) / shift() Add to the start / remove the first item
indexOf(x) / includes(x) Find the position / check if the item exists
forEach(fn) Run a function for every item
map(fn) Make a new array from the results of a function
filter(fn) Make a new array with items that pass a test
join(", ") Join items into one string 
const nums = [1, 2, 3];
nums.push(4);                         // [1, 2, 3, 4]
const doubled = nums.map(n => n * 2); // [2, 4, 6, 8]
const big = nums.filter(n => n > 2);  // [3, 4]
nums.forEach(n => console.log(n));

for (let i = 0; i < nums.length; i++) {
  console.log(nums[i]);
}
for (const n of nums) {
  console.log(n);
}

The Document Object Model (DOM)

The DOM represents all page content as objects that can be modified. The document object is the main entry point to the page. It defines the logical structure of an HTML document and how it is accessed and manipulated. Anything in an HTML document can be accessed, changed, deleted or added using the DOM. Everything in HTML, even comments, becomes a part of the DOM.

Selecting HTML elements

Method Searches by
querySelector CSS selector (first match)
querySelectorAll CSS selector (all matches)
getElementById id
getElementsByName name
getElementsByTagName tag or "*"
getElementsByClassName class 
const title = document.getElementById("title");
const items = document.querySelectorAll("#list li");
const form  = document.querySelector('form[name="search"]');
const first = form.querySelector("input");

Changing text, styles, classes, attributes

title.textContent = "New title";      // only text, safe
box.innerHTML = "<b>Bold</b>";        // parses HTML, risky (XSS)
title.style.color = "red";            // inline CSS
title.classList.add("active");        // also remove(), toggle()
link.setAttribute("href", "page.html");
link.getAttribute("href");

textContent vs innerHTML: textContent only changes the text of a node. It is faster (no HTML parsing) and more secure (it will not run code). innerHTML is more powerful because it can change code, but it is less secure: it allows cross-site scripting (XSS).

Creating and removing elements

const ul = document.querySelector("#list");
const topics = ["HTML", "CSS", "JS"];

topics.forEach(function (t) {
  const li = document.createElement("li&");
  li.textContent = t;
  ul.appendChild(li);        // add to the page
});

ul.removeChild(ul.firstElementChild);   // remove one item

Week 8: JS Events and Form Validation

Events make a page interactive: JavaScript reacts to clicks, key presses, typing and form submission.

Event listeners

Event listeners allow JavaScript to react to user interactions like clicks and key presses. The function that runs when the event happens is a callback.

const btn = document.querySelector("#btn&");
let count = 0;

btn.addEventListener("click", function (event) {
  count++;
  btn.textContent = "Clicked: " + count;
});
Group Events
Mouse click, dblclick, mouseenter, mouseleave
Keyboard keydown, keyup
Form submit, input, change, focus, blur
Document / window DOMContentLoaded, load, resize, scroll

Keyboard events

The KeyboardEvent object handles events that occur when a user presses a key.

Property Returns
key The value of the key that triggered the event ("a", "Enter")
code The code of the physical key ("KeyA")
ctrlKey / altKey / shiftKey true if that modifier key was pressed
location Where the key is: 0 almost every key, 1 left, 2 right, 3 Numpad, 4 mobile, 5 game controller
repeat true if the key is being held down 
document.addEventListener("keydown", function (e) {
  if (e.ctrlKey && e.key === "s") {
    e.preventDefault();         // stop the browser default
    console.log("Save!");
  }
});

Objects

Objects are collections of key-value pairs. Keys are strings (or symbols) and values can be any data type, including other objects or functions (called methods). Properties store data and methods are functions inside the object. Access properties with dot notation (person.name) or bracket notation (person["name"]). Properties can be added, modified or deleted at runtime.

const person = {
  name: "John",
  age: 30,
  greet() {
    return "Hi, I am " + this.name;
  }
};
person.age = 31;           // change
person.city = "Astana";    // add
delete person.age;         // delete
console.log(person.greet());

Callbacks and event responses

A callback is a function passed into another function as an argument and executed later. Event handlers, setTimeout and forEach all use callbacks.

function done() { console.log("Finished"); }
setTimeout(done, 1000);    // done runs after 1 second
[1, 2].forEach(function (n) { console.log(n); });

Sounds and animation

Create an Audio object to play a sound; it is an audio player with play() and pause() methods. requestAnimationFrame() allows smooth, frame-by-frame animations.

const sound = new Audio("click.mp3");
sound.play();

let x = 0;
function move() {
  x += 2;
  box.style.left = x + "px";
  if (x < 300) requestAnimationFrame(move);
}
requestAnimationFrame(move);

Form validation with RegEx

Client-side validation checks the data before the form is sent. A regular expression (RegEx) describes a text pattern; regex.test(text) returns true or false. If the data is wrong, call event.preventDefault() in the submit handler and show a message.

const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

form.addEventListener("submit", function (e) {
  const email = form.email.value.trim();
  if (email === "" || !emailRegex.test(email)) {
    e.preventDefault();                       // block sending
    error.textContent = "Enter a valid email";
  }
});
Pattern Meaning
^ and $ Start and end of the text
\d A digit
\S Any character except a space
+ and * One or more / zero or more times
[a-z] One character from the range

Week 9: jQuery

What is jQuery?

jQuery is a JavaScript library that streamlines the creation of dynamic behavior with predefined methods for selecting and manipulating DOM elements. It offers a simplified approach to responsiveness and needs fewer lines of code than traditional JavaScript. jQuery was originally released in January 2006 at BarCamp NYC by John Resig.

jQuery inclusion

Download the library from jQuery.com, or include it from a CDN (Content Delivery Network).

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

Syntax and the Document Ready event

Basic syntax: $(selector).action(). The $ sign defines and accesses jQuery, (selector) queries (finds) HTML elements and action() is performed on the element(s). The .ready() method waits until the DOM is fully rendered and then invokes the callback function.

$(document).ready(function () {
  $("p").hide();
});

// short form
$(function () {
  $("p").show();
});

Selectors

Syntax Description
$("*") Selects all elements
$(this) Selects the current HTML element
$("p.intro") All p elements with class="intro"
$("p:first") The first p element
$("ul li:first") The first li of the first ul
$("ul li:first-child") The first li of every ul
$("[href]") All elements with an href attribute
$("a[target='_blank']") Links whose target is "_blank"
$("a[target!='_blank']") Links whose target is NOT "_blank"
$(":button") All button elements and inputs of type button
$("tr:even") / $("tr:odd") Even / odd table rows

Event methods

Mouse Keyboard Form Document / window
click keypress submit load
dblclick keydown change resize
mouseenter keyup focus scroll

Effects

Effects: hide(), show(), toggle(), fadeIn(), fadeOut(), fadeToggle(), slideUp(), slideDown(), slideToggle() and animate() for custom animations.

$("#box").fadeOut(400);
$("#box").slideToggle("slow");
