Live Coding — Week 2: CSS Basics

Three coding tasks. Write your code in your editor (for example VS Code) or in the box below, then press Show Solution to compare.

Task 1: Three types of CSS

Make one page that uses all three types of CSS.

  • Inline CSS: make the h1 blue with the style attribute
  • Internal CSS: in a <style> tag in <head> make every p green
  • External CSS: link the file css/style.css with the <link> tag

Expected result

My page

This text is green.

Solution

<!DOCTYPE html>
<html>
<head>
  <title>CSS types</title>
  <link rel="stylesheet" href="css/style.css">
  <style>
    p {
      color: green;
    }
  </style>
</head>
<body>
  <h1 style="color: blue;">My page</h1>
  <p>This text is green.</p>
</body>
</html>

Task 2: Selectors and text formatting

Style a heading, a note and links with different selectors.

  • ID selector #main-title: font-size: 32px and text-align: center
  • Class selector .note: text-transform: uppercase and a web-safe font Georgia, serif
  • Descendant selector nav a: remove the underline with text-decoration: none

Expected result

Welcome

Read the lecture first

Home Quiz

Solution

<h1 id="main-title">Welcome</h1>
<p class="note">Read the lecture first</p>
<nav>
  <a href="#">Home</a>
  <a href="#">Quiz</a>
</nav>

/* CSS */
#main-title {
  font-size: 32px;
  text-align: center;
}
.note {
  text-transform: uppercase;
  font-family: Georgia, serif;
}
nav a {
  text-decoration: none;
}

Task 3: Box model and positioning

Make a product card with a badge in the corner.

  • .card: padding: 20px, border: 2px solid, margin: 16px
  • .card must be position: relative
  • .badge: position: absolute, top: 10px, right: 10px

Expected result

Product cardNEW

Solution

<div class="card">
  Product card
  <span class="badge">NEW</span>
</div>

/* CSS */
.card {
  position: relative;
  padding: 20px;
  border: 2px solid #0b3b8c;
  margin: 16px;
}
.badge {
  position: absolute;
  top: 10px;
  right: 10px;
  background: #0b3b8c;
  color: white;
  padding: 2px 8px;
}
