Quiz - Week 8: JS Events and Form Validation

11 questions: 8 on theory and 3 on code. Choose your answers, then press Check Answers.

1. Which method attaches a click handler to an element?

Correct answer: el.addEventListener("click", fn). addEventListener(type, callback) registers a function that runs when the event happens.

2. What does event.preventDefault() do?

Correct answer: Stops the default action, for example sending a form. It cancels the default browser action of the event, such as form submission or following a link.

3. Which KeyboardEvent property gives the value of the pressed key?

Correct answer: event.key. event.key returns the value ("a", "Enter"). event.code is the physical key and location tells where it is on the keyboard.

4. What does event.ctrlKey return?

Correct answer: true if the CTRL key was pressed, otherwise false. ctrlKey, altKey and shiftKey are booleans that show if a modifier key was pressed.

5. What is a callback?

Correct answer: A function passed as an argument and executed later. A callback is a function passed into another function and executed later, like an event handler.

6. Which two ways read the property name of the object person?

Correct answer: person.name and person["name"]. JavaScript uses dot notation and bracket notation.

7. Which RegExp method returns true or false for a text?

Correct answer: regex.test(text). regex.test(text) returns true if the text matches the pattern.

8. Which event fires every time the user types in an input?

Correct answer: input. The input event fires on every change of the field value, so it is used for real-time validation.

9. What is printed? 
const user = { name: "Aida", age: 19 };
user.age = 20;
console.log(user.name, user.age);

Correct answer: Aida 20. The age property is changed at runtime from 19 to 20.

10. What is printed? 
const re = /^\S+@\S+\.\S+$/;
console.log(re.test("aida@mail"));

Correct answer: false. The pattern needs a dot and more characters after the @ part. "aida@mail" has no dot, so the result is false.

11. What happens when the input is empty? 
form.addEventListener("submit", function (e) {
  if (input.value === "") {
    e.preventDefault();
  }
});

Correct answer: The form is not sent. preventDefault() cancels the submission when the field is empty.

Green = correct answer, red = your wrong choice.
