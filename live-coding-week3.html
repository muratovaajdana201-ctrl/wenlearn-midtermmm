Live Coding - Week 3: Flexbox and Grid

Three coding tasks. Write your code in your editor (for example VS Code) or in the box below, then press Show Solution to compare.

Task 1: Flexbox navigation bar

Put the logo and the menu links in one line.

  • The container .menu uses display: flex
  • Items are spread with justify-content: space-between
  • Items are centered on the cross axis with align-items: center; no bullets (list-style: none)

Expected result

  • Logo
  • Home
  • Lectures
  • Quiz

Solution

<ul class="menu">
  <li>Logo</li>
  <li>Home</li>
  <li>Lectures</li>
  <li>Quiz</li>
</ul>

/* CSS */
.menu {
  display: flex;
  justify-content: space-between;
  align-items: center;
  list-style: none;
  padding: 12px;
  background: #0b3b8c;
  color: white;
}

Task 2: Center a block

Center a text block inside a box, both horizontally and vertically.

  • .box has height: 200px and a border
  • Use Flexbox on .box
  • Center with justify-content (main axis) and align-items (cross axis)

Expected result

I am centered

Solution

<div class="box">
  <p>I am centered</p>
</div>

/* CSS */
.box {
  height: 200px;
  border: 2px dashed #4db8ff;
  display: flex;
  justify-content: center;
  align-items: center;
}

Task 3: Grid gallery

Build a photo gallery layout with CSS Grid.

  • .gallery uses display: grid
  • Three equal columns: grid-template-columns: repeat(3, 1fr)
  • gap: 20px, and the first item takes two columns: grid-column: 1 / 3

Expected result

1
2
3
4
5

Solution

<div class="gallery">
  <div class="wide">1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
  <div>5</div>
</div>

/* CSS */
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
.wide {
  grid-column: 1 / 3;
}
.gallery div {
  background: #4db8ff;
  padding: 20px;
}
