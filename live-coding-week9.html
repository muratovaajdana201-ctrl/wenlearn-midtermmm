Live Coding - Week 9: jQuery

Three coding tasks. Write your code in your editor or in the box below, then press Show Solution to compare.

Task 1: Selectors and document ready

Select elements and change them when the DOM is ready.

  • Wrap the code in $(document).ready(function () { ... })
  • Make all p.intro blue with .css() and add the class first to the first li of the ul
  • Select links with target="_blank" and add the text " (new tab)" with .append()

Expected result

Intro paragraph

  • First item
  • Second item
External link (new tab)

Solution

<p class="intro">Intro paragraph</p>
<ul>
  <li>First item</li>
  <li>Second item</li>
</ul>
<a href="https://jquery.com" target="_blank">External link</a>

<script>
  $(document).ready(function () {
    $("p.intro").css("color", "blue");
    $("ul li:first").addClass("first");
    $("a[target='_blank']").append(" (new tab)");
  });
</script>

Task 2: Events and effects

Use jQuery events with fade and slide effects.

  • A button #toggleBtn toggles #box with .slideToggle() on click
  • On mouseenter the box gets the class hover, on mouseleave it is removed
  • A second button #hideBtn hides #msg with .fadeOut()

Expected result

A box that slides up and down

Solution

<button id="toggleBtn">Toggle box</button>
<button id="hideBtn">Hide message</button>
<div id="box">A box that slides up and down</div>
<p id="msg">Hello!</p>
<script>
  $("#toggleBtn").click(function () {
    $("#box").slideToggle();
  });

  $("#box").on("mouseenter", function () {
    $(this).addClass("hover");
  }).on("mouseleave", function () {
    $(this).removeClass("hover");
  });

  $("#hideBtn").click(function () {
    $("#msg").fadeOut();
  });
</script>

Task 3: Traversing and a dynamic list

Add and remove list items with jQuery.

  • Input #task, button #add and ul#todo; on click append a new li with the text from .val()
  • Every li has a button.del; on click remove the item with $(this).closest("li").remove()
  • Clicking the text of an item toggles the class done with .toggleClass(); use .on() on ul#todo so new items work too

Expected result

  • Read lecture
  • Take the quiz

Solution

<input id="task" placeholder="New task">
<button id="add">Add</button>
<ul id="todo"></ul>
<script>
  $("#add").click(function () {
    const text = $("#task").val().trim();
    if (text !== "") {
      $("#todo").append(
        "<li><span>" + $("<div>").text(text).html() + "</span> " +
        "<button class='del'>x</button></li>"
      );
      $("#task").val("");
    }
  });

  $("#todo").on("click", ".del", function () {
    $(this).closest("li").remove();
  });

  $("#todo").on("click", "span", function () {
    $(this).toggleClass("done");
  });
</script>
