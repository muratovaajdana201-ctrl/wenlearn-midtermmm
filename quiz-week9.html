Quiz - Week 9: jQuery

11 questions: 8 on theory and 3 on code. Choose your answers, then press Check Answers.

1. What is jQuery?

Correct answer: A JavaScript library with predefined methods for selecting and manipulating DOM elements. jQuery is a JavaScript library that simplifies DOM manipulation and needs fewer lines of code.

2. What is the basic jQuery syntax?

Correct answer: $(selector).action(). $ accesses jQuery, (selector) finds the elements and action() is done on them.

3. What does $(document).ready() do?

Correct answer: Waits until the DOM is fully rendered and then runs the callback. The ready method makes sure the code runs only after the DOM is built.

4. What does $("p.intro") select?

Correct answer: All p elements with class="intro". It is the CSS selector: tag p with the class intro.

5. Which method selects all direct children of an element?

Correct answer: .children(). .children() gives direct children only. .find() searches all descendants.

6. What does .closest() return?

Correct answer: The nearest matching element, including itself or its ancestors. .closest() goes up the tree from the element and returns the first match.

7. Which method reads or sets the value of a form field?

Correct answer: .val(). .val() is used for inputs, selects and textareas. .text() and .html() work with element content.

8. Which event is used for typing into an input in real time?

Correct answer: input (or keyup). The input and keyup events fire while the user types.

9. What does this code do? 
$("#box").addClass("active");

Correct answer: Adds the class "active" to the element with id="box". addClass() adds one or more CSS classes to the selected elements.

10. Which elements are changed? 
$("a[target='_blank']").css("color", "red");

Correct answer: Links that open in a new tab (target="_blank"). The attribute selector [target='_blank'] matches only links with that target value.

11. What happens when the button is clicked? 
$("#btn").click(function () {
  $("#msg").fadeToggle();
});

Correct answer: The message fades out if visible and fades in if hidden. fadeToggle() switches between fadeIn and fadeOut for the selected element.

Green = correct answer, red = your wrong choice.
