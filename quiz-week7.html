Quiz — Week 7: Arrays, Loops and DOM Manipulation

10 questions: 7 on theory and 3 on code. Choose your answers, then press Check Answers.

1. What is the index of the first element of an array?

Correct answer: 0. Array indexes start from 0.

2. Which method adds a new item to the end of an array?

Correct answer: push(). push() adds to the end, pop() removes the last item. unshift() and shift() work with the start.

3. Which method runs a function for every item of an array?

Correct answer: forEach(). forEach() calls the function once for each array item.

4. What does DOM stand for and what is it?

Correct answer: Document Object Model, the page as objects that JavaScript can change. The Document Object Model represents all page content as objects. Anything in an HTML document can be accessed, changed, deleted or added with it.

5. Which method returns the first element that matches a CSS selector?

Correct answer: querySelector(). querySelector() takes a CSS selector and returns the first match. querySelectorAll() returns all matches.

6. Why is textContent safer than innerHTML?

Correct answer: It does not parse HTML, so it will not run injected code (XSS). innerHTML parses HTML and can run injected code (XSS). textContent only sets text, so it is faster and more secure.

7. Which code adds the CSS class "active" to an element?

Correct answer: el.classList.add("active"). classList has add(), remove() and toggle() methods for CSS classes.

8. What is printed? 
const fruits = ["apple", "banana"];
fruits.push("kiwi");
console.log(fruits.length);

Correct answer: 3. push adds "kiwi" to the end, so the array has 3 items.

9. What does this code do? 
document.querySelector("h1").textContent = "Hi";

Correct answer: Changes the text of the first h1 to "Hi". querySelector returns only the first h1 and textContent replaces its text.

10. What is printed? 
const nums = [1, 2, 3];
const doubled = nums.map(n => n * 2);
console.log(doubled);

Correct answer: [2, 4, 6]. map() builds a new array from the result of the function for each item: [2, 4, 6].

Green = correct answer, red = your wrong choice.
