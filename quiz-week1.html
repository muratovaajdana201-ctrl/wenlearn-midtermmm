Quiz — Week 1: HTML Basics

13 questions: 10 on theory and 3 on code. Choose your answers, then press Check Answers.

1. What does HTML stand for? Theory

Correct answer: Hyper Text Markup Language. HTML is the Hyper Text Markup Language, the standard markup language for creating web pages.

2. According to the lecture, what is HTML responsible for on a web page? Theory

Correct answer: How the page is structured. HTML gives the STRUCTURE, CSS controls how the page LOOKS and JavaScript controls how it FUNCTIONS.

3. Which three container elements make a true HTML document? Theory

Correct answer: <html>, <head>, <body>. <html> wraps everything, <head> holds the title and styles, <body> holds the content you see.

4. Which heading tag makes the largest heading? Theory

Correct answer: <h1>. Headings go from <h1> (largest) to <h6> (smallest).

5. What is the difference between an HTML tag and an attribute? Theory

Correct answer: A tag tells the browser what to do, an attribute tells it how to do it. The <tag> tells the browser to do something, and the attribute (for example href or src) gives the details.

6. Which tag forces a line break without starting a new paragraph? Theory

Correct answer: <br>. <br> starts a new line, like single spacing in a document. <p> starts a new paragraph.

7. In a table, what does <th> mean? Theory

Correct answer: Table header cell. <tr> is a table row, <td> is table data and <th> is a table header cell.

8. Which list shows its items with numbers? Theory

Correct answer: <ol> (ordered list). <ol> is ordered (1, 2, 3), <ul> is unordered (bullets). Every item is an <li>.

9. Why is <img> called an empty tag? Theory

Correct answer: It has only attributes and no closing tag. <img> has no content and no closing tag; the picture comes from the src attribute.

10. To publish a site on GitHub Pages, what must the main HTML file be called? Theory

Correct answer: index.html. GitHub Pages opens index.html first, so the main page of the project must be called index.html.

11. Which line is nested correctly? Code 
<p><b><em>Text</p></em></b>
<p><b><em>Text</em></b></p>

Correct answer: The second line. The last tag opened must be the first tag closed: em closes first, then b, then p.

12. What will this code show in the browser? Code 
<a href="https://du.astanait.edu.kz/login">DU Astana IT University</a>

Correct answer: The text DU Astana IT University as a clickable link. The words between <a> and </a> become the link; href holds the address it opens.

13. What does colspan="2" do here? Code 
<tr>
  <th colspan="2">Average age</th>
</tr>

Correct answer: The cell spans (takes the width of) two columns. colspan joins cells across columns; rowspan joins cells across rows.

Green = correct answer, red = your wrong choice.
