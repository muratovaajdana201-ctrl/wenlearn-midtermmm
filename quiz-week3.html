Quiz — Week 3: Flexbox and Grid

10 questions: 8 on theory and 2 on code. Choose your answers, then press Check Answers.

1. Flexbox is a layout method that is… Theory

Correct answer: one-dimensional (a row or a column). Flexbox arranges items in one direction: a row or a column. Grid is the two-dimensional system.

2. What are flex items? Theory

Correct answer: The direct children of a flex container. Only the direct children of the element with display: flex become flex items.

3. What is the cross axis in Flexbox? Theory

Correct answer: The axis perpendicular to the main axis. The main axis is set by flex-direction; the cross axis always goes across it (perpendicular).

4. Which property aligns flex items along the cross axis? Theory

Correct answer: align-items. align-items works on the cross axis. justify-content works on the main axis.

5. Which property overrides align-items for one single flex item? Theory

Correct answer: align-self. align-self is set on an item and overrides the container's align-items only for that item.

6. What is the default value of the order property? Theory

Correct answer: 0. All flex items have order: 0 by default, so they appear in the same order as in the HTML.

7. What does the fr unit mean in CSS Grid? Theory

Correct answer: A fraction of the available space. fr is a fractional unit: 1fr 2fr splits the free space into three parts, giving 1 and 2 parts.

8. According to the lecture, when should you use Grid instead of Flexbox? Theory

Correct answer: Full page layouts, dashboards and galleries. Grid is best for complex two-dimensional layouts. Flexbox is best for one-direction things like navbars and menus.

9. How will the items of .menu be arranged? Code 
.menu {
  display: flex;
  flex-direction: column;
}

Correct answer: One under another, top to bottom. flex-direction: column makes the main axis vertical, so the items stack from top to bottom.

10. What layout does this code create? Code 
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 32px;
}

Correct answer: Three equal columns with 32px between them. repeat(3, 1fr) means three columns of one fraction each, so they are equal; gap adds 32px between tracks.

Green = correct answer, red = your wrong choice.
