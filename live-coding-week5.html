Live Coding — Week 5: Bootstrap Grid and Components

Three coding tasks. Write your code in your editor (for example VS Code) or in the box below, then press Show Solution to compare.

Task 1: Responsive navbar

Build a Bootstrap navbar that collapses on small screens.

  • Use navbar navbar-expand-lg bg-light with a navbar-brand
  • Add a toggler button with data-bs-toggle="collapse" and data-bs-target="#menu"
  • Put three links (Home, Lectures, Quiz) in navbar-nav inside collapse navbar-collapse

Expected result

WebLearn
  • Home
  • Lectures
  • Quiz

Solution

<nav class="navbar navbar-expand-lg bg-light">
  <div class="container">
    <a class="navbar-brand" href="#">WebLearn</a>
    <button class="navbar-toggler" type="button"
            data-bs-toggle="collapse" data-bs-target="#menu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item"><a class="nav-link" href="#">Home</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Lectures</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Quiz</a></li>
      </ul>
    </div>
  </div>
</nav>

Task 2: A grid of cards

Show three lecture cards in a responsive grid.

  • Use container → row g-4 → three columns col-12 col-md-4
  • Each column has a card with card-body, card-title, card-text
  • Add a btn btn-primary button to every card

Expected result

Week 1

HTML Basics

Read
Week 2

CSS Basics

Read
Week 3

Flexbox and Grid

Read

Solution

<div class="container">
  <div class="row g-4">
    <div class="col-12 col-md-4">
      <div class="card">
        <div class="card-body">
          <h5 class="card-title">Week 1</h5>
          <p class="card-text">HTML Basics</p>
          <a href="#" class="btn btn-primary">Read</a>
        </div>
      </div>
    </div>
    <!-- repeat for Week 2 and Week 3 -->
  </div>
</div>

Task 3: Modal window

Open a Bootstrap modal with a button.

  • A btn btn-primary button with data-bs-toggle="modal" and data-bs-target="#info"
  • A modal fade with id="info" containing modal-dialog and modal-content
  • The modal has a header with a title, a body with text and a footer with a Close button (data-bs-dismiss="modal")

Expected result

Hello
This is a modal window.

Solution

<button class="btn btn-primary" data-bs-toggle="modal"
        data-bs-target="#info">Open</button>

<div class="modal fade" id="info" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Hello</h5>
      </div>
      <div class="modal-body">This is a modal window.</div>
      <div class="modal-footer">
        <button class="btn btn-secondary"
                data-bs-dismiss="modal">Close</button>
      </div>
    </div>
  </div>
</div>

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
