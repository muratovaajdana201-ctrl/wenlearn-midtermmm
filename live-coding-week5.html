Live Coding - Week 5: Forms and Validation

Three coding tasks. Write your code in your editor or in the box below, then press Show Solution to compare.

Task 1: A form with HTML5 validation

Build a registration form that uses the built-in HTML5 validation.

  • Add a form with an email input (type="email", required) and a password input (minlength="8", required)
  • Add an age input: type="number" with min="16" and max="100"
  • Add a submit button

Expected result

Solution

<form action="/register" method="post">
  <label for="email">Email</label>
  <input type="email" id="email" name="email" required>
  <label for="password">Password</label>
  <input type="password" id="password" name="password" minlength="8" required>
  <label for="age">Age</label>
  <input type="number" id="age" name="age" min="16" max="100">
  <button type="submit">Register</button>
</form>

Task 2: Bootstrap form components

Style the form with Bootstrap and show the invalid state.

  • Wrap the email field in a div with the class mb-3, use form-label and form-control
  • Add the class is-invalid to the input
  • Add a div with the class invalid-feedback and the text Please enter a valid email.

Expected result

Please enter a valid email.

Solution

<div class="mb-3">
  <label for="userEmail" class="form-label">Email</label>
  <input type="email" class="form-control is-invalid" id="userEmail" required>
  <div class="invalid-feedback">Please enter a valid email.</div>
</div>

Task 3: JavaScript validation

Check the form with JavaScript before it is sent.

  • Select the form with id registerForm and add a submit listener
  • If form.checkValidity() is false, call event.preventDefault()
  • Add the class was-validated to the form

Expected result

Empty required field + Submit = the form is not sent and the fields are marked red.

Solution

const form = document.querySelector("#registerForm");
form.addEventListener("submit", function (event) {
  if (!form.checkValidity()) {
    event.preventDefault();
    event.stopPropagation();
  }
  form.classList.add("was-validated");
});
