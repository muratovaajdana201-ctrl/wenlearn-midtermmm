Live Coding — Week 8: JS Events and Form Validation

Three coding tasks. Write your code in your editor (for example VS Code) or in the box below, then press Show Solution to compare.

Task 1: Click counter

React to a button click.

  • HTML: button id="counter" with the text "Clicked: 0"
  • Use addEventListener("click", ...) to increase a variable and update textContent
  • Change the button color with style.background when the count reaches 5

Expected result

Solution

<button id="counter">Clicked: 0</button>

<script>
  const btn = document.getElementById("counter");
  let count = 0;

  btn.addEventListener("click", function () {
    count++;
    btn.textContent = "Clicked: " + count;
    if (count === 5) {
      btn.style.background = "green";
    }
  });
</script>

Task 2: Keyboard events and objects

Show information about the pressed key.

  • Listen to keydown on document
  • Store key and ctrlKey in an object and show them in p id="info"
  • When Ctrl + Enter is pressed show an alert("Sent!")

Expected result

Key: a, Ctrl: false

Solution

<p id="info">Press any key</p>

<script>
  document.addEventListener("keydown", function (e) {
    const pressed = { key: e.key, ctrl: e.ctrlKey };
    document.getElementById("info").textContent =
      "Key: " + pressed.key + ", Ctrl: " + pressed.ctrl;

    if (e.ctrlKey && e.key === "Enter") {
      alert("Sent!");
    }
  });
</script>

Task 3: Form validation

Validate a small form before it is sent.

  • A form with name, email and a submit button; every field must be filled
  • Check the email with a RegEx (regex.test())
  • If something is wrong, call preventDefault() and show a red message in p id="error"; otherwise show a green "Success"

Expected result

Enter a valid email

Solution

<form id="form">
  <input id="name" placeholder="Name">
  <input id="email" placeholder="Email">
  <button type="submit">Send</button>
  <p id="error"></p>
</form>

<script>
  const form = document.getElementById("form");
  const error = document.getElementById("error");
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

  form.addEventListener("submit", function (e) {
    const name = document.getElementById("name").value.trim();
    const email = document.getElementById("email").value.trim();

    if (name === "" || email === "") {
      e.preventDefault();
      error.style.color = "red";
      error.textContent = "Fill in all fields";
    } else if (!emailRegex.test(email)) {
      e.preventDefault();
      error.style.color = "red";
      error.textContent = "Enter a valid email";
    } else {
      error.style.color = "green";
      error.textContent = "Success";
    }
  });
</script>
