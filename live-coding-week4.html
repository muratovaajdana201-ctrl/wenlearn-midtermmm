Live Coding — Week 4: Bootstrap and Media Queries

Three coding tasks. Write your code in your editor (for example VS Code) or in the box below, then press Show Solution to compare.

Task 1: Bootstrap grid

Make a responsive row of three columns with Bootstrap.

  • Connect Bootstrap with the CDN link in <head>
  • Use the structure container → row → columns
  • Each column is col-12 col-md-4: full width on phones, one third from 768px

Expected result

Column 1
Column 2
Column 3

Solution

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

<div class="container">
  <div class="row">
    <div class="col-12 col-md-4">Column 1</div>
    <div class="col-12 col-md-4">Column 2</div>
    <div class="col-12 col-md-4">Column 3</div>
  </div>
</div>

Task 3: Media queries

Make the page change on small screens.

  • On desktop .menu is a flex row
  • @media (max-width: 768px): .menu becomes a column (flex-direction: column)
  • @media (max-width: 575px): h1 gets font-size: 24px

Expected result

Make the browser window narrower to see it change:

  • Home
  • Lectures
  • Quiz

Solution

.menu {
  display: flex;
  gap: 12px;
}

@media (max-width: 768px) {
  .menu {
    flex-direction: column;
  }
}

@media (max-width: 575px) {
  h1 {
    font-size: 24px;
  }
}
