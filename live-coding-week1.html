Live Coding — Week 1: HTML Basics

Three coding tasks. Write your code in your editor (for example VS Code) or in the box below, then press Show Solution to compare.

Task 1: Page skeleton, headings and paragraphs

Build a correct HTML document about yourself.

  • Start with <!DOCTYPE html>, then <html>, <head> with a <title>, and <body>
  • Add an <h1> with your name and an <h2> “About me”
  • Write two paragraphs <p>; inside the first one use <br> and <b><em> nested correctly

Expected result

Aidana Muratova

About me

I study at Astana IT University.
My major is Software Engineering.

I like web development.

Solution

<!DOCTYPE html>
<html>
<head>
  <title>About me</title>
</head>
<body>
  <h1>Aidana Muratova</h1>
  <h2>About me</h2>
  <p>I study at <b><em>Astana IT University</em></b>.<br>
  My major is Software Engineering.</p>
  <p>I like web development.</p>
</body>
</html>

Task 2: Table with a header and colspan

Make a table of the course schedule.

  • Use <table> with a <caption>, <thead> and <tbody>
  • The header row uses <th> cells: Week, Topic
  • Add a last row with one cell that spans both columns: colspan="2"

Expected result

Course schedule
WeekTopic
1HTML Basics
2CSS Basics
Midterm project

Solution

<table border="1">
  <caption>Course schedule</caption>
  <thead>
    <tr>
      <th>Week</th>
      <th>Topic</th>
    </tr>
  </thead>
  <tbody>
    <tr><td>1</td><td>HTML Basics</td></tr>
    <tr><td>2</td><td>CSS Basics</td></tr>
    <tr><td colspan="2">Midterm project</td></tr>
  </tbody>
</table>

Task 3: Lists, links and an image

Make a small page about useful resources.

  • An unordered list <ul> of three tools: VS Code, GitHub, Chrome DevTools
  • An ordered list <ol> with the steps to publish a site on GitHub Pages
  • A link <a href="..."> to W3Schools and an image <img src="..." alt="...">

Expected result

Tools

  • VS Code
  • GitHub
  • Chrome DevTools

Publish your site

  1. Create a repository
  2. Upload index.html
  3. Enable GitHub Pages in Settings

Learn more HTML on W3Schools

Solution

<h2>Tools</h2>
<ul>
  <li>VS Code</li>
  <li>GitHub</li>
  <li>Chrome DevTools</li>
</ul>

<h2>Publish your site</h2>
<ol>
  <li>Create a repository</li>
  <li>Upload index.html</li>
  <li>Enable GitHub Pages in Settings</li>
</ol>

<a href="https://www.w3schools.com/html/html_intro.asp">Learn more HTML on W3Schools</a>
