Quiz — Week 4: Bootstrap and Media Queries

11 questions: 8 on theory and 3 on code. Choose your answers, then press Check Answers.

1. What is Bootstrap? Theory

Correct answer: An open-source front-end framework with ready-made classes. Bootstrap is an open-source front-end framework (created at Twitter) with ready-made CSS classes and components.

2. How many columns does the Bootstrap grid have? Theory

Correct answer: 12. The Bootstrap grid is based on 12 columns, so col-4 + col-4 + col-4 fill one row.

3. What is the correct structure of the Bootstrap grid? Theory

Correct answer: container → row → columns. A container wraps a row, and the row groups the columns.

4. What is the difference of .container-fluid? Theory

Correct answer: It spans the full width of the viewport. .container-fluid is always 100% wide. .container has a fixed max-width that changes at each breakpoint.

5. Bootstrap follows which approach to responsive design? Theory

Correct answer: Mobile-first. Bootstrap is mobile-first: styles start from small screens and classes like col-md- add changes for wider ones.

6. From which screen width does the md breakpoint start? Theory

Correct answer: 768px. sm starts at 576px, md at 768px, lg at 992px and xl at 1200px.

7. What is the easiest and fastest way to add Bootstrap to a page? Theory

Correct answer: A CDN link in the <head>. A CDN <link> in the head is the quickest. You can also download the files or use npm install bootstrap.

8. What is a media query? Theory

Correct answer: A CSS feature that applies styles based on device characteristics. A media query applies CSS only when a condition is true, for example max-width, min-width or orientation.

9. The screen is 800px wide. How much space does this column take? Code 
<div class="col-12 col-md-3 col-lg-2">
  Sidebar
</div>

Correct answer: 3 of the 12 columns. 800px is at least 768px (md) but less than 992px (lg), so col-md-3 is used: 3 of 12 columns.

10. When is this CSS applied? Code 
@media (max-width: 575px) {
  h1 {
    font-size: 24px;
  }
}

Correct answer: Only on screens 575px wide or narrower. max-width: 575px means the rule works only while the screen is 575px or less, so on phones.

11. What do these Bootstrap classes do? Code 
<p class="text-center text-danger mt-3">
  Error!
</p>

Correct answer: Red centered text with margin-top 1rem. text-center centers the text, text-danger makes it red and mt-3 adds a margin-top of 1rem.

Green = correct answer, red = your wrong choice.
