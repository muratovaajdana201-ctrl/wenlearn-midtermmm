Quiz - Week 5: Forms and Validation

10 questions: 7 on theory and 3 on code. Choose your answers, then press Check Answers.

1. Which attribute of the <form> element defines the URL where the data is sent?

Correct answer: action. action is the submission URL. method only chooses how the data is sent (GET or POST).

2. Which attribute identifies the value of an input when the form is submitted to the server?

Correct answer: name. The server receives the values as name=value pairs. id is used by CSS, JavaScript and labels.

3. Which HTML5 attribute does not allow the field to stay empty?

Correct answer: required. The browser blocks the submission and shows a message if a required field is empty.

4. Which HTML5 attribute checks a text value with a regular expression?

Correct answer: pattern. pattern holds a regular expression. There is no regex attribute in HTML.

5. Which Bootstrap class is used for a text input?

Correct answer: form-control. form-label is for labels, form-select for dropdowns and form-check for checkboxes and radio buttons.

6. Which Bootstrap class shows the red error state of an input?

Correct answer: is-invalid. It works together with invalid-feedback for the message. is-valid shows the green state.

7. Which method checks that all HTML validation rules of a form are satisfied?

Correct answer: form.checkValidity(). It returns true if all fields follow their rules (required, minlength, pattern and so on).

8. What is printed? 
const regex = /^\d+$/;
console.log(regex.test("2026"));

Correct answer: true. ^ is the start, \d+ is one or more digits and $ is the end. "2026" has only digits, so test returns true.

9. What happens when the user types 12 and presses Submit? 
<input type="number" name="age" min="16" max="100">

Correct answer: The browser blocks the submission and shows a message. 12 is smaller than min="16", so the HTML5 validation fails.

10. What happens when the required field is empty and the user presses Submit? 
form.addEventListener("submit", function (event) {
  if (!form.checkValidity()) {
    event.preventDefault();
  }
});

Correct answer: The form is not sent. checkValidity() returns false, so preventDefault() stops the default action: sending the form.
