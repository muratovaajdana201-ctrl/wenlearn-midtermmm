Quiz — Week 5: Bootstrap Grid and Components

10 questions: 7 on theory and 3 on code. Choose your answers, then press Check Answers.

1. Which classes create a navbar that collapses on screens smaller than 992px?

Correct answer: navbar navbar-expand-lg. navbar-expand-lg means: expanded from the lg breakpoint (992px) and up, collapsed into a hamburger button below it.

2. Which Bootstrap component is a flexible box with an image, a body, a title and text?

Correct answer: Card. A card (card, card-body, card-title, card-text) groups content in one box.

3. Which file is needed for the modal, collapse and carousel to work?

Correct answer: bootstrap.bundle.min.js. Interactive components need Bootstrap JavaScript. The bundle also includes Popper, so it is the easiest choice.

4. Which attributes connect a button to a modal with id="info"?

Correct answer: data-bs-toggle="modal" data-bs-target="#info". data-bs-toggle says what to do (modal) and data-bs-target says which element (#info).

5. What does g-4 do on a .row?

Correct answer: Adds spacing (gutters) between the columns. g-* sets the gutter: the space between columns. gx-* is horizontal and gy-* is vertical only.

6. What do the order-* classes change?

Correct answer: The visual order of the columns. order-1, order-2 ... change the visual order of columns without changing the HTML.

7. Which class shows a red warning message box?

Correct answer: alert alert-danger. alert alert-danger makes a red alert. alert-success is green and alert-warning is yellow.

8. How is this column placed on a screen 1000px wide? 
<div class="row">
  <div class="col-md-6 offset-md-3">Hello</div>
</div>

Correct answer: 6 columns wide, centered. 1000px is at least md (768px), so col-md-6 gives 6 columns and offset-md-3 leaves 3 empty columns on the left. 3 + 6 + 3 = 12: centered.

9. What happens with these columns? 
<div class="row">
  <div class="col-8">A</div>
  <div class="col-6">B</div>
</div>

Correct answer: B moves to the next line. 8 + 6 = 14, which is more than 12, so column B wraps to a new line.

10. When is this element visible? 
<div class="d-none d-lg-block">Sidebar</div>

Correct answer: Only from 992px (lg) and up. d-none hides it everywhere, d-lg-block shows it again from the lg breakpoint (992px).

Green = correct answer, red = your wrong choice.
