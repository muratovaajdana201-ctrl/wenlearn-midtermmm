Live Coding — Week 6: JavaScript Basics

Three coding tasks. Write your code in your editor (for example VS Code) or in the box below, then press Show Solution to compare.

Task 1: Variables and output

Practice let, const, data types and console output.

  • Create const university = "AITU" and let students = 100
  • Increase students by 5 with +=
  • Print one line with a template literal and print typeof students

Expected result

AITU has 105 students
number

Solution

const university = "AITU";
let students = 100;
students += 5;

console.log(`${university} has ${students} students`);
console.log(typeof students);   // "number"

Task 2: Conditions

Write a function that returns a grade by score.

  • Create function getGrade(score)
  • Return "A" for 90 and more, "B" for 70 and more, "C" for 50 and more, otherwise "F"
  • Call it with 95, 72 and 30 and print the results

Expected result

A
B
F

Solution

function getGrade(score) {
  if (score >= 90) return "A";
  else if (score >= 70) return "B";
  else if (score >= 50) return "C";
  return "F";
}

console.log(getGrade(95));  // A
console.log(getGrade(72));  // B
console.log(getGrade(30));  // F

Task 3: Loops

Use loops to print a table and calculate a sum.

  • With a for loop print the multiplication table of 5 from 1 to 5, for example 5 x 1 = 5
  • With a while loop calculate the sum of numbers from 1 to 10
  • Print the sum (it must be 55)

Expected result

5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
Sum: 55

Solution

for (let i = 1; i <= 5; i++) {
  console.log(`5 x ${i} = ${5 * i}`);
}

let n = 1;
let sum = 0;
while (n <= 10) {
  sum += n;
  n++;
}
console.log("Sum: " + sum);   // Sum: 55
