Quiz — Week 6: JavaScript Basics

11 questions: 8 on theory and 3 on code. Choose your answers, then press Check Answers.

1. Who created JavaScript at Netscape Communications?

Correct answer: Brendan Eich. Brendan Eich created JavaScript while working at Netscape Communications for the browser.

2. What is the role of JavaScript on a web page?

Correct answer: It adds behavior and interactivity. HTML is the skeleton, CSS is the clothes and JavaScript adds life: behavior and interactivity.

3. Which keyword is the default choice for values that do not change?

Correct answer: const. Use const by default. Use let when the value changes (counter, score, total). Avoid var.

4. What is the scope of a variable declared with var?

Correct answer: Function scope. var has function scope. let and const have block scope.

5. Which method writes into the browser developer console?

Correct answer: console.log(). console.log() prints into the developer console. alert() opens a pop-up and document.write() writes into the page.

6. What is the difference between == and ===?

Correct answer: === compares both type and value, == converts types first. == converts types before comparing, === requires the same type and the same value. Always use === and !==.

7. Which loop always runs its body at least once?

Correct answer: do...while. do...while checks the condition after the body, so the body runs at least once.

8. What does typeof "AITU" return?

Correct answer: "string". The typeof operator returns the type name. A text value is a "string".

9. What is printed? 
console.log("5" + 3);

Correct answer: "53". The + operator with a string concatenates: the number 3 becomes text, so the result is "53".

10. What is printed? 
console.log(10 % 3, 2 ** 3);

Correct answer: 1 8. 10 % 3 is the remainder of the division (1) and 2 ** 3 is 2 to the power of 3 (8).

11. What is printed? 
let sum = 0;
for (let i = 1; i <= 4; i++) {
  sum += i;
}
console.log(sum);

Correct answer: 10. The loop adds 1 + 2 + 3 + 4 = 10.

Green = correct answer, red = your wrong choice.
