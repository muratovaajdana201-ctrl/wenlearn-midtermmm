Final Test — Weeks 1–9

27 questions from all nine lectures. Choose your answers, then press Check Answers to see your score.

1. What does HTML stand for?

Correct answer: Hyper Text Markup Language. HTML is the Hyper Text Markup Language, the standard markup language for creating web pages.

2. Which tag forces a line break without starting a new paragraph?

Correct answer: <br>. <br> starts a new line, like single spacing in a document. <p> starts a new paragraph.

3. What does colspan="2" do here? 
<tr>
  <th colspan="2">Average age</th>
</tr>

Correct answer: The cell spans (takes the width of) two columns. colspan joins cells across columns; rowspan joins cells across rows.

4. What does CSS stand for?

Correct answer: Cascading Style Sheets. CSS means Cascading Style Sheets. It makes pages presentable and keeps styling separate from the HTML.

5. Which selector is used to target one specific, unique element?

Correct answer: ID selector (#header). An ID must be unique on the page, so #header selects only one element. Classes can be shared by many elements.

6. How will the text look in the browser? 
h2 {
  text-transform: uppercase;
  text-align: center;
}

<h2>Hello world</h2>

Correct answer: HELLO WORLD, centered. text-transform: uppercase changes all letters to capitals and text-align: center centers the line.

7. Flexbox is a layout method that is…

Correct answer: one-dimensional (a row or a column). Flexbox arranges items in one direction: a row or a column. Grid is the two-dimensional system.

8. Which property overrides align-items for one single flex item?

Correct answer: align-self. align-self is set on an item and overrides the container's align-items only for that item.

9. What layout does this code create? 
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 32px;
}

Correct answer: Three equal columns with 32px between them. repeat(3, 1fr) means three columns of one fraction each, so they are equal; gap adds 32px between tracks.

10. What is Bootstrap?

Correct answer: An open-source front-end framework with ready-made classes. Bootstrap is an open-source front-end framework (created at Twitter) with ready-made CSS classes and components.

11. Bootstrap follows which approach to responsive design?

Correct answer: Mobile-first. Bootstrap is mobile-first: styles start from small screens and classes like col-md- add changes for wider ones.

12. What do these Bootstrap classes do? 
<p class="text-center text-danger mt-3">
  Error!
</p>

Correct answer: Red centered text with margin-top 1rem. text-center centers the text, text-danger makes it red and mt-3 adds a margin-top of 1rem.

13. Which classes create a navbar that collapses on screens smaller than 992px?

Correct answer: navbar navbar-expand-lg. navbar-expand-lg means: expanded from the lg breakpoint (992px) and up, collapsed into a hamburger button below it.

14. What does g-4 do on a .row?

Correct answer: Adds spacing (gutters) between the columns. g-* sets the gutter: the space between columns. gx-* is horizontal and gy-* is vertical only.

15. How is this column placed on a screen 1000px wide? 
<div class="row">
  <div class="col-md-6 offset-md-3">Hello</div>
</div>

Correct answer: 6 columns wide, centered. 1000px is at least md (768px), so col-md-6 gives 6 columns and offset-md-3 leaves 3 empty columns on the left. 3 + 6 + 3 = 12: centered.

16. Who created JavaScript at Netscape Communications?

Correct answer: Brendan Eich. Brendan Eich created JavaScript while working at Netscape Communications for the browser.

17. What is the difference between == and ===?

Correct answer: === compares both type and value, == converts types first. == converts types before comparing, === requires the same type and the same value. Always use === and !==.

18. What is printed? 
let sum = 0;
for (let i = 1; i <= 4; i++) {
  sum += i;
}
console.log(sum);

Correct answer: 10. The loop adds 1 + 2 + 3 + 4 = 10.

19. What is the index of the first element of an array?

Correct answer: 0. Array indexes start from 0.

20. Which method returns the first element that matches a CSS selector?

Correct answer: querySelector(). querySelector() takes a CSS selector and returns the first match. querySelectorAll() returns all matches.

21. What is printed? 
const fruits = ["apple", "banana"];
fruits.push("kiwi");
console.log(fruits.length);

Correct answer: 3. push adds "kiwi" to the end, so the array has 3 items.

22. Which method attaches a click handler to an element?

Correct answer: el.addEventListener("click", fn). addEventListener(type, callback) registers a function that runs when the event happens.

23. Which two ways read the property name of the object person?

Correct answer: person.name and person["name"]. JavaScript uses dot notation and bracket notation.

24. What happens when the input is empty? 
form.addEventListener("submit", function (e) {
  if (input.value === "") {
    e.preventDefault();
  }
});

Correct answer: The form is not sent. preventDefault() cancels the submission when the field is empty.

25. What is jQuery?

Correct answer: A JavaScript library with predefined methods for selecting and manipulating DOM elements. jQuery is a JavaScript library that simplifies DOM manipulation and needs fewer lines of code.

26. What does .closest() return?

Correct answer: The nearest matching element, including itself or its ancestors. .closest() goes up the tree from the element and returns the first match.

27. What does this code do? 
$("#box").addClass("active");

Correct answer: Adds the class "active" to the element with id="box". addClass() adds one or more CSS classes to the selected elements.
