Live Coding — Week 7: Arrays, Loops and DOM Manipulation

Three coding tasks. Write your code in your editor (for example VS Code) or in the box below, then press Show Solution to compare.

Task 1: Arrays and loops

Work with an array of lecture topics.

  • Create const topics = ["HTML", "CSS", "Flexbox"]
  • Add "Bootstrap" with push() and remove the first item with shift()
  • Print every item with forEach() and print the length

Expected result

CSS
Flexbox
Bootstrap
Length: 3

Solution

const topics = ["HTML", "CSS", "Flexbox"];
topics.push("Bootstrap");   // add to the end
topics.shift();             // remove "HTML"

topics.forEach(function (topic) {
  console.log(topic);
});
console.log("Length: " + topics.length);

Task 2: Changing the DOM

Select elements and change their text, style and class.

  • Select the heading with id="title" and change its textContent to "Hello, DOM!"
  • Change its color to blue with style.color
  • Select the first paragraph with querySelector("p") and add the class highlight with classList

Expected result

Hello, DOM!

This paragraph has the class "highlight".

Solution

<h1 id="title">Old title</h1>
<p>This paragraph has the class "highlight".</p>

<script>
  const title = document.getElementById("title");
  title.textContent = "Hello, DOM!";
  title.style.color = "blue";

  document.querySelector("p").classList.add("highlight");
</script>

Task 3: Mini-app: a list from an array

Show an array on the page and add new items with a button.

  • HTML: an input id="newItem", a button id="addBtn" and an empty ul id="list"
  • JavaScript: loop over an array and create an li for each item with createElement and appendChild
  • On button click add the text of the input as a new li and clear the input

Expected result

  • HTML
  • CSS
  • JavaScript

Solution

<input id="newItem" placeholder="New topic">
<button id="addBtn">Add</button>
<ul id="list"></ul>

<script>
  const topics = ["HTML", "CSS", "JavaScript"];
  const list = document.getElementById("list");

  function addItem(text) {
    const li = document.createElement("li");
    li.textContent = text;
    list.appendChild(li);
  }

  topics.forEach(addItem);

  document.getElementById("addBtn").addEventListener("click", function () {
    const input = document.getElementById("newItem");
    if (input.value.trim() !== "") {
      addItem(input.value.trim());
      input.value = "";
    }
  });
</script>
